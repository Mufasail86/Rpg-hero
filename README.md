# Герой

Лист персонажа и пошаговый конструктор для **D&D 5e** и **Pathfinder 2e**. Это обычный сайт без сервера: персонажи, фото и броски живут в памяти телефона. Удобно открывать с мобильного Safari.

Готовая страница: <https://mufasail86.github.io/Rpg-hero/>

Она заработает после двух шагов, которые делает владелец репозитория:

1. Влить этот код в ветку `main`.
2. На GitHub открыть **Settings → Pages → Build and deployment** и поставить **Source: GitHub Actions**.

Пока источник Pages не GitHub Actions, по адресу выше будет пусто или старая заглушка. Workflow сам выкладывает сайт при каждом пуше в `main`. Пул-реквесты только собирают и тестируют, в интернет их не публикуют.

## Как открыть на телефоне

Откройте ссылку в Safari или Chrome. Можно добавить страницу на экран «Домой»: в Safari это «Поделиться» → «На экран Домой». Приложение откроется почти на весь экран.

Создание идёт по шагам: система, имя, народ, происхождение, класс, характеристики, навыки, черты, снаряжение и, если класс колдует, заклинания. На листе крупные кнопки. Характеристики, навыки, хиты, инвентарь, опыт, вдохновение или очки героизма, заклинания и кости открываются отдельным экраном.

Кнопка ℹ️ у правила объясняет по-русски, что оно делает.

Кости: к4, к6, к8, к10, к12, к20 и к100, модификатор, преимущество и помеха. К6 крутится кубиком, остальные — фишками. На iPhone сначала нажмите «Разрешить встряхивание», затем телефон можно встряхнуть.

Несколько героев хранятся в `localStorage`. «Экспорт JSON» скачивает файл, «Импорт JSON» возвращает его на другой телефон. Фото сжимается и никуда не отправляется.

## Что внутри каталога

D&D 5e, только SRD 5.2 / открытые правила 5.1:

- народы: драконорождённый, дварф, эльф, гном, голиаф, полурослик, человек, орк, тифлинг;
- происхождения: послушник, преступник, мудрец, солдат;
- все 12 классов и по одному подклассу справочника;
- покупка очков, стандартный набор и 4d6;
- навыки, состояния, стартовые наборы и короткие описания заклинаний заговора и 1-го круга.

Pathfinder 2e, лицензия ORC, ремастер Player Core:

- народы: дварф, эльф, гном, гоблин, полурослик, человек, леший, орк, с наследиями и чертами 1-го уровня;
- 16 происхождений;
- классы: бард, жрец, друид, воин, следопыт, плут, ведьма, волшебник;
- повышения характеристик, навыки, объём, очки героизма, заговоры и заклинания 1-го круга.

Если нужного варианта нет, в каждом списке есть **«Своя запись»**.

Подробные уведомления о лицензиях — в [ATTRIBUTION.md](ATTRIBUTION.md) и на главном экране, кнопка «Об игре и лицензиях».

## Запустить у себя

Нужен Node.js 22.

```bash
npm ci
npm test
npm run dev
```

Сайт откроется на `http://localhost:5173`. Сборка:

```bash
npm run build
npm run preview
```

Папка `dist` — готовый статический сайт.

## Как выложить у друга

Скопируйте содержимое `dist` на любой хостинг файлов: GitHub Pages, Netlify, nginx, даже общая папка. Пути в сборке относительные (`./`), поэтому сайт работает и в корне домена, и в подпапке вроде `/Rpg-hero/`. Менять `base` в `vite.config.ts` не нужно.

Если хост — тоже GitHub Pages, оставьте workflow `.github/workflows/pages.yml` и включите источник **GitHub Actions**, как сказано выше.
