# Приёмка

Числа контрольного воина «Артефол Побочка» считаются из `progress` и надетых предметов. Имени в формуле нет. Заметка на листе в расчёт не входит. Цели задания совпали с ремастером Player Core, подгонять их не пришлось.

| --- | --- |
| Сила / Ловкость / Телосложение | +6 / +5 / +5 |
| Интеллект / Мудрость / Харизма | 0 / +4 / 0. У Мудрости 18 и незакрытое частичное повышение |
| ПЗ с Живучестью | 328. Без черты 308, разница ровно уровень |
| Скорость с Быстроногим | 30. Без черты 25 |

| Скрытность легенда | +33 |
| Медицина легенда | +32 |
| Воровство и Акробатика, мастер | +31 и +31 |
| Воля с Дальновидностью | +30, ранг мастер |

| КБ в чешуе | 41. С дуэльным парированием 43, и эти +2 не входят в выключенный КБ |

## Сценарии

1. Живучесть добавляет и снимает только свой уровень хитов. Автотест `Живучесть добавляет и снимает только свой уровень хитов`.
2. Быстроногий даёт +5 футов и снимается вместе с чертой. Автотест есть.
3. Владение оружием воина: эксперт с 1, группа мечей мастер с 5, легенда с 13, на 20 уровне не эксперт. Лук на 5 остаётся экспертом, на 13 становится мастером. Автотест есть.
4. Свой доспех с бонусом +4 и пределом Ловкости +0 даёт КБ 40 и объём 5 вместе с мечом и луком. Автотест есть. Форма в «Развитии» подписывает бонус, предел, объём, порог Силы и категорию.
5. Визит доктора считается отдельно на 1 и на 2 действия. Второй в том же раунде останавливает черта «усилие». Автотест `Визит доктора есть на 1 и на 2 действия`.
6. Боевая медицина пишет иммунитет по имени цели. Другая цель лечится. Новый раунд иммунитет не стирает. Автотест есть.
7. Мастерство навыка на 10 уровне поднимает Акробатику с эксперта до мастера и Воровство с обученного до эксперта и даёт черту. Новых обученных навыков нет. Автотест есть.
8. Смена навыка умелого наследия на Общество заново ломает Мастерство навыка: это ошибка сборки, Акробатика не остаётся мастером. Автотест есть.
9. Экспорт версии 2 и импорт копией переносят выборы, заметку, изображение и предметы. Битый JSON текущий список не заменяет. Автотесты в `src/transfer.test.ts`. Перед записью список кладётся в запасной ключ.
10. Персонажи живут в `localStorage`. Повторное открытие страницы их читает. В собранном сайте сервис-воркер отдаёт оболочку без сети. В режиме разработки воркер не регистрируется, чтобы Vite не застревал в старой копии.
11. Готовый воин D&D 5e по-прежнему создаётся прежним путём. Автотест `создаёт воина D&D 5e`. Шаг черт волшебника больше не запирается на «Общей подготовке»: черта навыка без обученности показывает причину, пустой список классовых черт шаг не блокирует.

Синхронизация между устройствами не делалась: это следующий приоритет, только по желанию и без автоматической публикации.
